# 静电场 · 空间实验室

2026-10-14 第二版：大学物理 JC05 的五个概念与案例入口。

## 页面

- index.html：电场与运动。轨迹结束自动显示沿途受力，另可显示沿途电场、空间电场；点圆点读取位置、电场与力。修改源后需重新发射。
- field.html：电场叠加。源到黄色点的虚线给出作用方向和距离，分场与合场同步变化。
- slice.html：电势定义 → 等势面 → 改变参考零点 → 零电势仍有电场；切片用于解释三维面如何成为二维交线。
- flux.html：面片的穿入/穿出 → 电荷跨越闭合面 → 面的形变。净通量与包围电荷联动，积分说明折叠。
- cases.html：照片墙 → 具体事件 → 照片与过程模型 → 该案例自己的 5W2H。
- analysis.html：旧链接兼容，打开同一案例工作区，不是独立的 5W2H 页面。支持 ?case=valley、glenpool、desmoines、esd、esp。

三维页面支持旋转缩放，控件有标签与焦点提示。逐步展开内容，每屏先处理一个问题。手机采用上下布局。

## 证据与图片

assets/cases 包含 14 张本地图片，manifest.json 和页面逐图注明来源、性质与许可。Valley Center 火灾、Glenpool 残骸属于对应事件照片；Des Moines 使用调查图与标明非事故现场的实验火花照片。NASA 损伤显微图来自地面试验，器件、腕带、除尘器照片为实物参考。不同事件的照片不互相冒充。

事故模型依据调查与结构资料建立，比例和运动过程做教学简化，不是事故数值重建。调查中“最可能”的路径保持为推断；无数据的电压、火花能量、尺寸和除尘率不虚构。5W2H 回答对应当前案例，附原始来源。

## 物理模型

源为固定、均匀带电绝缘球，球外为库仑场，球内为均匀体电荷解析解。场与势来自同一组源。电势页演示不同参考零点，其余默认 V(无穷远)=0。绝缘球不代表有限金属电极，不模拟感应重分布。

试探粒子采用电子电荷与质量，积分 m dv/dt=qE。正电试验粒子保持电子质量，不标成质子。轨迹实际计算，无预制路径。重力、阻力、磁场、辐射和反作用未纳入；球面碰撞吸收粒子。长度 mm，时间 ns，动画慢放，粒子显示尺寸放大。

高斯面是观察面，形变不改变源。有限源球跨界时以精确相交体积计算包围电荷，独立表面积分校核通量；页面解释归一化读数。

## 运行与验收

运行 node serve.mjs，打开 http://127.0.0.1:4173。图形库与图片本地提供，无外部 CDN 依赖。ES 模块需通过 HTTP，不能直接双击 HTML。

npm test 运行 16 项物理测试；node build.mjs 生成 dist，包括案例图片与语音。原始语音响应不进入发布包，Three.js 许可证保留。

第二版浏览器验收覆盖受力图层、叠加虚线、电势参考、三维截面、通量跨界与变形、案例图片和阶段、同案例 5W2H；390 px 布局无横向溢出。

这是可体验与评审的课程样板，尚未覆盖整章 12 学时。有限金属电极、导体静电平衡等仍需继续开发。
