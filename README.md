# 静电场 · 空间实验室

2026-10-14 首期六页交互样板。大学物理 JC05 静电场。

## 入口与操作

- `index.html` 粒子操控：调整两组固定电荷，让电子进入空间目标；可比较前次轨迹、暂停、逐点回看、切换电荷正负与发射速度。点选公式把 q、E、F 与模型联系起来。
- `field.html` 场的叠加：点选取样平面放探针；改变两源电荷，比较分场、合场与电势。
- `slice.html` 三维与切片：移动 XY / XZ 平面；空间探针与二维取样图对应；“发现零电势面”展示 V=0、法向 E 非零。
- `flux.html` 高斯通量：改变闭合面的形状与位置，加入外部电荷，点选面片，比较数值积分与 Q内/ε₀。
- `cases.html` 事故与应用墙：3 起调查来源事故、NASA ESD 风险场景及 EPA 静电除尘应用，支持筛选、详情、证据边界与原文链接。
- `analysis.html` 5W2H：案例七问、可切断的定性点火链、假设参数下的储能比较。

所有三维页面都支持旋转、缩放与标准视角。二维截面有键盘探针控制；控件有标签与焦点提示。手机采用上下排列。

## 物理模型

源是固定、均匀带电绝缘球，球外使用库仑场，球内使用均匀体电荷的解析解。电场和电势来自同一组源，V(无穷远)=0。绝缘球不代表有限金属电极，也不模拟导体感应重分布。

试探粒子默认采用电子电荷与质量，积分 m dv/dt = qE。正电试验粒子保持电子质量，不标成质子。轨迹由计算产生，没有预制命中路径；重力、介质阻力、磁场、辐射和反作用未纳入。球面碰撞吸收粒子。长度 mm、时间 ns，动画统一慢放，粒子显示尺寸放大。

高斯面是观察面；形变不改变源。表面通量为数值积分。源球与面部分相交时提示边界，不把整个电荷错误代入。事故因果链是定性教学模型；储能参数为假设，不反推事故火花参数或宣称现场安全。

## 运行与导出

在此目录运行 `node serve.mjs`，打开 `http://127.0.0.1:4173`。模块和图形库都在本地，运行无需外部 CDN；请通过 HTTP 打开，不能直接双击 HTML 使用 ES 模块。

`node build.mjs` 生成静态 `dist`。可部署到支持静态网页的服务。音频原始响应与制作记录不进入公开构建。Three.js 许可证保留在 vendor/THREE-LICENSE.txt。
