# 静电场 · 空间实验室

2026-10-15 第三版：大学物理 JC05 的六个概念与案例入口。

## 页面

- index.html：电场与运动。默认密集的 XY 场切面，可切 XZ、移动切面或查看三维样点。用实际计算的快慢/强弱双轨迹比较偏转；选一个轨迹点查看 E、F、v。修改源后需重新发射。
- field.html：电荷与场。默认沉浸画面、XZ 水平面的固定三维箭头；拖动电荷或自动往复，箭头原地转向和伸缩。参数默认收起，可展开叠加、源到黄点虚线和局部 E/F，也可切空间场线与 XY 流纹。长度与明度采用固定的压缩映射，精确场强看读数。
- slice.html：指定路径移动正试探电荷，比较功与势能 → 沿等势面移动，观察力与移动方向垂直 → 改变参考零点 → 零电势仍有电场。切片作为解释三维面与二维交线的可选工具。
- flux.html：先观察发散场，再加入包围面，比较穿入/穿出 → 电荷跨越闭合面 → 面的形变 → 测净通量推断隐藏的净电荷。积分说明折叠。
- cases.html：照片墙 → 具体事件 → 照片与过程模型 → 该案例自己的 5W2H。
- charge.html：金属球恒流充电、单次火花放电与实拍对照；进阶页默认以低机位观看 XZ 水平采样面上的蓝色辐射场箭头，随振荡沿 Y 起伏。参数、两探针的到达时延以及 E/B/传播方向收在展开区。
- analysis.html：旧链接兼容，打开同一案例工作区，不是独立的 5W2H 页面。支持 ?case=valley、glenpool、desmoines、esd、esp。

三维页面支持旋转缩放，控件有标签与焦点提示。逐步展开内容，每屏先处理一个问题。手机采用上下布局。

## 证据与图片

assets/cases 包含 14 张本地图片，manifest.json 和页面逐图注明来源、性质与许可。Valley Center 火灾、Glenpool 残骸属于对应事件照片；Des Moines 使用调查图与标明非事故现场的实验火花照片。NASA 损伤显微图来自地面试验，器件、腕带、除尘器照片为实物参考。不同事件的照片不互相冒充。

事故模型依据调查与结构资料建立，比例和运动过程做教学简化，不是事故数值重建。调查中“最可能”的路径保持为推断；无数据的电压、火花能量、尺寸和除尘率不虚构。5W2H 回答对应当前案例，附原始来源。

## 物理模型

前四页的源为均匀带电绝缘球，球外为库仑场，球内为均匀体电荷解析解。场与势来自同一组源。电势页演示不同参考零点，其余默认 V(无穷远)=0。叠加页移动源时显示各位置对应的静电快照，不模拟传播。绝缘球不代表有限金属电极，不模拟感应重分布。

方向纹理沿实际电场或其切面投影积分；纹理运动速度只为可读性，不代表电子速度。场线条数未按通量定标。实际粒子轨迹独立计算。电势页指定路径由外力控制，不能当成自由运动。

试探粒子采用电子电荷与质量，积分 m dv/dt=qE。正电试验粒子保持电子质量，不标成质子。轨迹实际计算，无预制路径。重力、阻力、磁场、辐射和反作用未纳入；球面碰撞吸收粒子。长度 mm，时间 ns，动画慢放，粒子显示尺寸放大。

高斯面是观察面，形变不改变源。有限源球跨界时以精确相交体积计算包围电荷，独立表面积分校核通量；页面解释归一化读数。

充电页单独采用等半径 20 mm 的两金属球：左球规定电势、右球接地，通过交替 Kelvin 像电荷满足两个等势边界，由总电荷得到电容。恒流输入为 5 nA，Q=CV，U=CV²/2；3 kV/mm 是示意触发阈值，真实击穿受环境及几何影响。放电后的指数回落仅作过程演示，不能预测真实火花时间或电流。

传播页仅显示低速、小振幅、远区的辐射项 E=kq[n×(n×a(t−r/c))]/(c²r)，B=n×E/c。q=1 nC，A=1 cm，f=30–90 MHz，20 m 内不画远区近似；源振幅在画面中放大 350 倍。近场、感应项、辐射反作用和材料边界未纳入，不能当成完整 Maxwell 场求解。

表现参考 ManimGL 的 ElectricDipole / StreamLines 示例，以及 3Blue1Brown 的 How wiggling charges give rise to light。本站为原创实时网页交互，没有把 Manim 录像或参考视频冒充本站仿真。

## 运行与验收

运行 node serve.mjs，打开 http://127.0.0.1:4173。图形库与图片本地提供，无外部 CDN 依赖。ES 模块需通过 HTTP，不能直接双击 HTML。

npm test 运行 28 项粒子、场线、高斯通量、金属球边界与辐射场的物理测试；node build.mjs 生成 dist，包括案例图片与语音。原始语音响应不进入发布包，Three.js 许可证保留。

第二版浏览器验收覆盖受力图层、叠加虚线、电势参考、三维截面、通量跨界与变形、案例图片和阶段、同案例 5W2H；390 px 布局无横向溢出。

这是可体验与评审的课程样板，尚未覆盖整章 12 学时。充电页已加入特定两球导体边界；任意形状金属电极、完整静电平衡习题及完整电磁波课程仍待扩展。

第三版浏览器验收覆盖六个入口、手拖源、自动往复/暂停、三种场表达、同号抵消、负电荷受力方向、充电/传播切换与清理、减弱动态效果偏好。低机位三维构图参照用户提供的3Blue1Brown视频截图，场的箭头留在空间采样点，方向/长度随实际计算更新。
