# 静电场 · 空间实验室

大学物理 JC05 交互课程样板。第四版改为本地运行与 GitHub Pages 分享。

## 打开与运行

- 在线课堂：https://syzhaoln-stack.github.io/electrostatic-space-lab/
- 源码：https://github.com/syzhaoln-stack/electrostatic-space-lab
- Windows：双击“启动本地课堂.cmd”。使用已安装的 Node.js；本机也可使用现有 Codex Node 运行时。无需安装 npm 依赖。
- 其他系统：`node serve.mjs`，打开 http://127.0.0.1:4173。
- `npm run build` 生成 dist；`npm run package:local` 生成 local-release，可复制到其他电脑后使用。

模块需要 HTTP 服务，不能直接双击 HTML。Three.js、图片、语音均随文件提供，课堂本身可离线使用；外部教材/视频/调查报告链接需要网络。服务只监听本机。其他端口可使用 `powershell -File start-local.ps1 -Port 4174`。

GitHub Actions 在 main 更新后先运行物理测试、再构建并发布 dist。本轮不再发布到 ChatGPT Sites；旧地址保留为旧版。

## 学习入口

1. **电子束**：首页默认粒子收集挑战（单束收集 → 加速并空间引导 → 移动出口），每批24个独立电子，速度和角度有确定性散布，实时计分与本机最佳。三个关卡按实际收集结果顺序解锁。先前单粒子练习在 particle.html：依次完成单向偏转、空间转向、速度挑战。XY / XZ 两个固定视窗同步显示同一次三维运动；场默认可见。命中后庆祝，点击下一关前进。任意时刻可以暂停、回看同一个位置的 E、F、v。
2. **电场的叠加**：默认两个源电荷、黄色观察点 P、源到 P 的虚线、两个分场与合场。拖动源或黄点看变化；同号/异号、正试探电荷/电子对照。仅保留空间箭头。单源与往复运动在展开设置中。
3. **电势与等势面**：移动做功、沿等势面移动、零电势仍有场。切平面与法向/位移直角直观表示做功关系；双电荷可显示整个合场。参考零点收在解释区。
4. **电通量与高斯定理**：看发散场、加入假想包围面、测净通量。可沿选定真实场线第一视角穿入/穿出，并用小图定位；对照外部正源一入一出与内部正源只出。部分外部场线不与面相交。
5. **真实事故与应用**：照片墙 → 发生了什么 → 四步过程播放 → 改变一个条件 → 当前案例的 5W2H。没有独立、脱离事故的 5W2H 页。
6. **充电与传播**：两金属球恒流充电与一次火花；运动点源的完整迟滞电场与传播分量对照。黑底、规则格点、清楚的蓝色三维箭头。

## 物理范围

前四页源为均匀带电绝缘球，球外库仑场、球内均匀体电荷解析解；电场与电势来自同一组源。场叠加页显示不同源位置对应的静电状态，不模拟传播。叠加页的两个源、观察点 P 和背景场取样均在 XY 平面（z=0），默认正视同一平面；空间视角只旋转镜头。默认放入电子看反向受力，点击平面即可选点。

运动页采用电子电荷与质量，积分 m dv/dt=qE。XY、XZ 场纹理分别取 z=0、y=0 平面的实际场投影；金色轨迹是同一次三维运动的两个投影，电子不必留在取样面上。纹理流动只帮助认方向，不代表电子速度。重力、阻力、磁场、辐射和反作用未计入。长度 mm，时间 ns，球面碰撞吸收粒子。

电势页的正试探电荷沿指定路径由外力控制；不是自由运动。W=-ΔU，沿等势面移动 W=0。任意参考零点不改变电场和电势差。

高斯面是观察面，不阻挡电场。源跨界按相交体积计算包围电荷，并用独立表面积分验证。跟随场线的运动是观察镜头，不是电子轨迹。外部源示范选择了确实与面相交的线。

充电页：两个半径20mm的金属球，一只充电、一只接地；交替 Kelvin 像电荷满足等势边界，由总电荷求电容。恒流5nA，Q=CV，U=CV²/2。3kV/mm仅是教学触发阈值，指数回落仅示意放电过程，不能预测真实击穿电压、火花时间或电流。

传播页：moving-charge-physics.js 计算预设运动点源的完整 Liénard–Wiechert 电场，包括速度/近场项与加速度项；解真实光锥方程确定迟滞时间，B=n×E/c。默认 q=1nC、振幅0.3m、15MHz；10–20MHz范围峰速低于0.13c。没有20m截断或人工软化，近处场真实存在；只避开点源奇点。球是放大的位置图标，不是有限金属球。完整E包含径向成分，只有加速度项与传播方向垂直。运动由外部规定，不计辐射反作用、材料和其他边界。箭头长度压缩，不可当作线性标尺。

## Blender 与 Godot

三起工业事故默认载入 Blender 建模、Godot 4.4.1 导出的交互装置。Des Moines 是依据 CSB 图建立的方形便携钢罐与喷嘴组件；Valley / Glenpool 使用有剖面的储罐模型，并按案例选择内部部件。外壳、阀门、管路、浮子等有独立结构。尺寸和过程用于教学，不是测绘模型或事故数值重建；电荷路径、场箭头、火花、火焰与烟雾均为定性示意，不输出未知电压或火焰尺度。

建模源与流程见 blender/README.md，GLB 在 assets/models，Godot 工程在 godot。Web 发布文件预导出到 assets/godot；单线程 WebGL2，无需跨源隔离。首次在线载入需要下载约44MB引擎，之后浏览器可缓存。Godot 叠加体验从场叠加页进入 engine.html；数学与原网页一致。

## 界面与束流模型

默认画面只保留实验与操作：顶部短导航，不展示章节编号和引导口号。参数靠近画面，长说明统一折叠；事故照片和5W2H可按需展开。XY、XZ与可旋转空间总览对应同一次束流计算。

beam-physics.js 采用RK4积分独立电子，单/双发射器，速度与角度散布、固定随机种子；静态加速与导向场由同一标量电势生成，含导向段纵向边缘场。负电子跨过加速段提高的电势时获得动能，静态满足ΔK=−qΔV。第三关是外部预设准静态时变导向，配合周期移动的圆孔；按到达时刻与真实三维圆孔距离计分，不能仅凭两个投影各自落在区间判断命中。不含电子间排斥、空间电荷、气体碰撞或反馈；所画电极是理想区域示意。
